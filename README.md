# SwagLabs
🚀 hashtag#AutomationTesting 🤖 | Selenium WebDriver with TestNG DataProvider & Listeners

🔍 Automated login functionality testcases using Selenium WebDriver, TestNG’s DataProvider annotation, and Listeners to execute tests with multiple credentials and enhance test reporting.

✅ Key Features:
🔹 Implemented Data-Driven Testing using DataProvider
🔹 Verified successful & failed login attempts
🔹 Utilized TestNG Listeners to capture test execution status dynamically
🔹 Generated test reports with detailed pass/fail logs

🛠 Tools & Technologies Used:
🔹 Selenium WebDriver – For browser automation
🔹 TestNG – For test execution, DataProvider, and Listeners
🔹 Java – For scripting & automation logic
🔹 Extent Reports – For test result documentation
🔹 GitHub – For version control & collaboration
